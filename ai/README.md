# Arquitectura del Servicio de IA - Gemini 
 
## Flujo de Trabajo del Proyecto 
1. Recoleccion de Datos: Acceso/Scraping de comercios en Google Maps y fichas publicas. 
2. Filtrado: Detectar negocios con baja puntuacion o pocas resenas. 
3. Almacenamiento: El Backend en Java guarda la informacion estructurada en DB. 
4. Procesamiento con Gemini: Analisis de sentimiento, scoring de leads y generacion de respuestas. 
5. Dashboard: Muestra las oportunidades de mejora y respuestas listas.
